# 微分动力（Differential Create）

微分动力是 Create 6.0.10 的动力学附属模组，适用于 Minecraft 1.21.1、NeoForge 21.1.238、Java 21。

动力源提供扭矩，负载和惯量决定转速。接入机器会降低转速，失去动力后会继续惰行；扭矩不足时逐渐停转。

## 玩法

- 水车、风车和蒸汽机按动力特性曲线输出，风车帆面积增加驱动力，锅炉供汽由发动机共享。
- 蒸汽机采用无内部阻力的有限扭矩/有限功率模型：默认每台低速缸压扭矩为 1024 su/RPM，高速由供汽限制功率。供汽充足时，256 RPM 是恒功率区起点；完全空载会继续加速，断汽后无负载则匀速惰行。单台最多利用一级供汽，满级锅炉需要 18 台才能利用全部 4,718,592 su；一台上限为 262,144 su。锅炉功率随有效等级线性增长。
- 体验时先用独立动力给锅炉供水，蒸汽输出只接轴，不接飞轮或工作机器。默认从静止约 1.5 秒到 256 RPM，1 分钟约 2275 RPM；有作弊权限时可用 `/tick sprint 1200t` 快进一分钟游戏时间。详细步骤和供汽、带载、断汽的预期现象见 [蒸汽机模型与体验指南](STEAM-MODEL-2026-09-16.md)。
- 并联蒸汽机按上游动力指令和速比选向，支持一致启动与主动反转；供汽关联失效时停止驱动并保留惰行，恢复供汽后继续加速。锅炉护目镜显示按新曲线计算的理论最大输出功率，保留尺寸、水量、热量及缺水提示。
- 动力泵按实际轴速输水，切断动力后仍可消耗转动储能继续供水，流量随惰行减速而下降；停转后停止供水。变速保持现有管路流动，改管和翻转泵方向时重新建立流路。
- 传动采用统一高刚度、无扭转阻尼的弹性连接，接合后允许持续振荡。冲击和持续过载均可能崩断传力路径上的部件，断裂保留此前已经交换的动量；拓扑连接本身不瞬间平均转速。试用场景、参数与验证见 [高刚度传动试用版](TORSION-2026-09-16.md)。
- 离合器支持红石强度调节：0 级完全接合、1–14 级调节压紧程度、15 级完全分离。传递扭矩上限为 `32 × (15 − 信号强度) / 15`；负载较轻时同步并锁止，超出摩擦能力时打滑。锁止不会取消扭矩上限；同侧连接和刚性旁路分别承受实际载荷。
- 黄铜离合器是新增的重载升级版，额定上限为 `1024 su/RPM`。空手瞄准侧面旋钮，长按右键即可打开 0–100% 咬合度滑条，无需扳手，步进 1%，默认 100%。实际扭矩上限为 `1024 × 设定咬合度 × (15 − 红石强度) / 15`；滑条 0% 或红石 15 均完全分离，撤去红石后恢复设定值。咬合度限制传递扭矩，轻负载下半联动也能同步锁止。设置支持存档、蓝图和剪贴板；滑条显示“咬合度”和百分比，护目镜保留实际传递扭矩与滑差。
- 转速控制器改为速比控制器：显示 `+2×` 表示输出为输入的两倍，负号反转，`0×` 断开。内部存档值仍为速比的 16 倍。
- 移除 Create 的转速上限设置。转速表量程独立于轴速：手持扳手瞄准表盘，按住右键选择 64、256、1024……1048576 RPM，默认 256。指针按实际转速绝对值线性移动，超量程保持满格；护目镜显示带符号的实际转速、量程和超量程提示。比较器按固定量程输出 0–15，停转为 0。量程随方块保存，也支持剪贴板复制。
- 冲压、石磨、搅拌、锯切、粉碎、机械手和机械合成按当前转速累计加工进度；停转保留进度。参考转速和适用范围见设计文档。
- 地面冲压会跳过无冲压配方的掉落物，成品留在原地也能继续投料；加工数量遵循 Create 的批量冲压配置。
- 具有工作循环的机器待机时不消耗扭矩，开始动作后恢复额定负载；冲压机的下压、加工和回程都计入工作。待机仍保留惯量，接入旋转网络时仍会分摊动量。鼓风机、泵等持续运转设备保留各自的负载规则，具体范围见设计文档。
- 飞轮惯量为 `0.5 su/RPM³`；轮体和中心轴共用网络角度，取消原版额外的起停缓动。普通渲染和 Flywheel 实例渲染使用相同运动。离合器空输出端完全分离后保持当时转速，有外接传动时跟随输出网络。
- 护目镜提供两种视图：正常时的动力学视图按设备显示实际转速、当前方块的转动惯量（`su/RPM³`）、扭矩、设备状态、动力源负载率，以及离合器滑差、速比和泵的等效扬程；潜行时查看本体动能、所属网络总动能和功率。蒸汽机沿用水车的视图布局，常驻显示转动惯量、转速、驱动状态、负载率和扭矩，状态为蒸汽驱动、无供汽或换向制动。底部提示当前绑定的潜行键。
- 负载率统一为所属网络的持续负载需求与当前可用驱动力之比：运行时按功率汇总，整体停转时按折算后的起动扭矩比较。包括工作机器、泵、风扇及实际传动损耗；飞轮加速和弹性储能不算负载。允许超过 100%，没有主动供能时显示“无动力”。读数由服务端同步，平衡转速下的 100% 表示收支平衡。定义和体验见 [负载率说明](LOAD-FACTOR-2026-09-16.md)。

加工改用双精度物理状态和实际轴行程，阶段结束后立即停止对应负载。相同配方、批量与完整动作的额定加工功在已适配路径中不再随 RPM 改变；验证结果与边界见 [加工耗功修正记录](MACHINING-2026-09-15.md)。

## 黄铜离合器配方

- **复合摩擦片 ×2**：铁板、皮革、黑曜石粉末、黏液球各 1 个，使用动力冲压机在工作盆中压块，无需加热。
- **黄铜离合器 ×1**：普通离合器、黄铜机壳、精密构件各 1 个，加复合摩擦片 4 个，工作台无序合成。

两种新物品位于“微分动力”（Differential Create）创造分类，搜索栏悬浮提示的蓝字也显示该名称，配方可在 JEI 中查看。黄铜框架与摩擦片均采用独立的方块/物品模型。制作与控制验证见 [黄铜离合器实现记录](BRASS-CLUTCH-2026-09-15.md)。

## 构建与验证

```powershell
.\gradlew.bat build runGameTestServer
```

Linux 对应命令为 `./gradlew build runGameTestServer`。首次运行需要下载依赖。

成品：`build/libs/differentialcreate-1.0.0.jar`。客户端和服务端均安装同一版本，并安装对应的 Create 及其依赖；同步兼容版本已升级为 5，不能与旧版客户端混用。

`build` 自动运行不依赖游戏启动的数值回归，包含 64 项蒸汽驱动和 204 项负载率断言；`runGameTestServer` 运行物理、拓扑、加工、碰撞、红石半联动、小惯量负载同步、风车移动结构转速、16 倍速弹性接合守恒、零待机负载、锁止离合器热接入、结构强度与刚性旁路、空输出端离合器，以及地面冲压连续投料、批量冲压、停转恢复，再加完整加工耗功、七个 16 倍速飞轮的精度复现、逐机变速/存档耗功、转速表量程/比较器/配置迁移，以及黄铜离合器控制与保存、重载传输、高速接入静止飞轮、制作配方链、创造分类与搜索物品栏重建、轴装配相位对齐、网络负载率读数与编码、九组蒸汽机和五组水泵回归，共四十组游戏测试。测试使用独立的 `run-gametest/`，无需删除开发世界 `run/world`。CI 同时执行这两项并保存测试日志。

最新构建及全部数值回归通过，全量 GameTest **40/40 通过**。负载率回归覆盖空载加速、机器待机/工作、停转、超载、并联动力和状态包编码；真实蒸汽风扇平衡时显示 100%，卸载后显示 0%，断汽后显示无动力。详情见 [负载率说明](LOAD-FACTOR-2026-09-16.md)。此前新增的 252 项求解精度断言也全部通过，原大惯量冲压用例耗能仍为 `12.80001513287425`，原断言及冲压逻辑未改动，见 [求解器精度修复记录](SOLVER-PRECISION-2026-09-16.md)。九组蒸汽机和五组水泵全部通过，体验步骤见 [蒸汽机模型与体验指南](STEAM-MODEL-2026-09-16.md)。此前的泵修复与旧转速标定保留在 [泵与蒸汽机调整记录](PUMP-STEAM-2026-09-16.md)。

若本机 Java 21 报 `Unable to establish loopback connection`，本次验证使用临时进程变量 `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=<一个不存在的目录>`，使 Java 的内部通信回退到 TCP；不需要修改系统环境变量。正常环境无需此设置。

## 当前边界

已通过的自动化验证不等于完成所有场景的验收。多人中途加入/切维度、真实跨区块卸载重载、Flywheel 开关两种渲染路径、复杂管网及全部配方组合还需要客户端实测。

泵采用管路端点平均高差的等效负载；运动结构惯量聚合覆盖机械轴承、钟表轴承、活塞和滑轮持有的结构。没有做真实流体动力学、方块质量分布或通用移动载具惯量。其他附属模组的特殊传动与加工逻辑没有全面验证。

数值标定目前集中在 `PhysicsTuning` 和 `InertiaRegistry`，尚未提供配置界面。
