# 微分动力（Differential Create）

微分动力是 Create 的动力学附属模组，模组 ID 为 `differentialcreate`。当前目标版本为 Minecraft 1.21.1、NeoForge 21.1.238、Create 6.0.10-281，使用 Java 21。

动力源提供扭矩，负载和惯量共同决定转速。机器带载会减速，断开动力后可以靠储能继续工作，动力不足时逐渐停转。

## 主要玩法

- **动力源**：水车和风车按动力曲线输出；蒸汽机共享锅炉供汽，低速受扭矩限制、高速受功率限制，默认空载趋近 512 RPM。断汽后保留惰行，外部动力可以使轴超过调速目标。搭建与观察步骤见 [蒸汽机体验指南](docs/STEAM.md)。
- **弹性传动**：轴、齿轮和机器通过有限刚度连接，接合后允许振荡，冲击与持续过载都可能崩断部件。安山等级强度为 65536、黄铜等级为 262144 su/RPM；创造马达本体为无限强度。
- **离合器**：红石 0 级接合、15 级分离、1–14 级调节传递扭矩。普通版额定上限为 1024、黄铜版为 32768 su/RPM。黄铜版可空手瞄准侧面旋钮并长按右键，设置 0–100% 咬合度；轻负载下半联动仍能同步，超限时打滑。
- **连续加工**：冲压、石磨、搅拌、锯切、粉碎、机械手、机械合成、静态方块破坏和机械臂动作按实际轴行程推进。停转保留进度，动作完成立即释放工作负载。鼓风加工随转速增加而加快，收益递减，仍需对应介质。
- **动态结构**：动力轴承空手右键组装或拆解，成功组装时输出从零速开始；风车、钟表轴承、活塞、滑轮和移动龙门架保留原有操作。结构质量、空气阻力和实际工具作业都会影响运动，稳定子结构也计入。操作与边界见 [动态结构说明](docs/CONTRAPTIONS.md)。
- **速比与指令**：转速控制器改为速比控制器，`+2×` 表示二倍增速，负号反转，`0×` 断开。可编程齿轮箱控制输出角度、距离和等待，按负载提前制动；同向连续动作可保持转速，反向与结束到位后停靠。见[动力行为与测试](docs/KINETIC_COVERAGE.md)。
- **储能与显示**：飞轮惯量为 0.5 su/RPM³，每只粉碎轮为 0.10。轴和机器动画播放服务器累计角度，护目镜显示实际转速、惯量、扭矩与结构强度；潜行查看本体和网络的动能、弹性势能与功率。
- **负载率**：运行时比较网络的持续需求功率与可用驱动功率，整体停转时比较起动扭矩。加速储能不算持续负载，100% 表示当前收支平衡，没有主动供能时显示“无动力”。
- **转速表**：移除原版轴速上限设置。手持扳手瞄准表盘并长按右键，可选择 64–1048576 RPM 量程；默认 256，指针与比较器按固定量程输出，超量程仍显示真实转速。

动力泵与管道使用不可压缩队列：新管全空气，每格保存有序的空气与真实流体，保留重力、水位差、泵负载与反拖。空管泵可以引液，没有排气路径会困气。正转速沿泵箭头增压，负转速逆箭头增压；扳手翻向或反转实际轴运动都可以调向。完整规则见 [流体说明](docs/FLUIDS.md)。

## 黄铜离合器配方

- **复合摩擦片 ×2**：铁板、皮革、黑曜石粉末、黏液球各 1 个，在工作盆中动力冲压，无需加热。
- **黄铜离合器 ×1**：工作台有序合成，黄铜机壳放上下、复合摩擦片放左右、中央放普通离合器。

两种新物品位于“微分动力”（Differential Create）创造分类，配方可在 JEI 中查看。咬合度支持存档、蓝图和剪贴板复制。

## 构建与验证

```powershell
.\gradlew.bat build runGameTestServer runVirtualAirServer
```

Linux 使用 `./gradlew build runGameTestServer runVirtualAirServer`，首次运行需要下载依赖。成品位于 `build/libs/differentialcreate-1.0.0.jar`。

客户端和服务端均安装同一版本，并安装对应的 Create 及其依赖。当前网络兼容版本为 **9**，不能与旧版客户端混用。

`build` 自动运行数值回归；`runGameTestServer` 验证拓扑、配方、物品控制、供汽和动态结构，默认使用 `run-gametest/`。`runVirtualAirServer` 在 `build/` 中运行流体、机器、动态管网与卸载场景，可用 `-PvirtualAirSelect=pump_direction_.*,structure_.*` 选择子集。CI 执行上述完整命令并保存日志，验证入口见 [设计文档](DESIGN.md#9-验证与维护) 和 [流体覆盖矩阵](docs/FLUID_COVERAGE.md)。

专项性能命令为 `.\gradlew.bat runFluidBenchmarkServer`，可用 `-PfluidPerfCase=loops` 选择多泵回路；类别和测量范围见 [性能测试](docs/FLUID_PERFORMANCE.md)。

## 当前边界与待办

结构使用等质量方块与外露面平方空气阻力，不模拟真实流场或水阻力。列车、矿车等独立载具及其他附属模组的特殊逻辑尚未全面适配。

管网不模拟真空、压缩、密度分层、同口逆向交换或管内反应，泛用机器使用近似水头。原生整数接口保留真实小数余量，普通重载不补气。流体预算不足时推迟更新，不积累补算任务。完整燃料链、多人中途加入或切维度、长期大型工厂、全部配方组合与完整客户端交互仍需专项验收。

参数目前集中在 `PhysicsTuning`、`InertiaRegistry` 和 `ContraptionGeometry`，黄铜强度名单使用方块标签，尚无配置界面。具体待办见 [设计文档](DESIGN.md#10-后续待办)。
