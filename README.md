# 微分动力（Differential Create）

微分动力是 Create 6.0.10 的动力学附属模组，适用于 Minecraft 1.21.1、NeoForge 21.1.238、Java 21。

动力源提供扭矩，负载和惯量决定转速。接入机器会降低转速，失去动力后会继续惰行；扭矩不足时逐渐停转。

## 玩法

- 水车、风车和蒸汽机按动力特性曲线输出，风车帆面积增加驱动力，锅炉供汽由发动机共享。
- 蒸汽机采用无内部阻力的有限扭矩/有限功率模型：默认每台低速缸压扭矩为 1024 su/RPM，高速由供汽限制功率。供汽充足时，256 RPM 是恒功率区起点；448–512 RPM 逐渐关闭进汽，将未使用的份额旁通排出，空载趋近 512 RPM。排汽越多，连续蒸汽粒子越密；实际供汽较弱时汽流也较弱。断汽后无负载则匀速惰行。单台最多利用一级供汽，满级锅炉需要 18 台才能利用全部 4,718,592 su；一台上限为 262,144 su。锅炉功率随有效等级线性增长。
- 体验时先用独立动力给锅炉供水，蒸汽输出只接轴，不接飞轮或工作机器。默认从静止约 1.5 秒到 256 RPM、4.2 秒到 500 RPM，随后趋近 512 RPM；有作弊权限时可用 `/tick sprint 1200t` 快进一分钟游戏时间。带载降速会重新进汽；外部动力可以使轴超过调速目标，此时蒸汽机停止同向驱动并排汽，不钳制轴速或自动制动。详细步骤见 [蒸汽机模型与体验指南](STEAM-MODEL-2026-09-16.md)。
- 并联蒸汽机按上游动力指令和速比选向，支持一致启动与主动反转；供汽关联失效时停止驱动并保留惰行，恢复供汽后继续加速。锅炉护目镜显示按新曲线计算的理论最大输出功率，保留尺寸、水量、热量及缺水提示。
- 动力泵按实际轴速输水，切断动力后仍可消耗转动储能继续供水，流量随惰行减速而下降；停转后停止供水。变速保持现有管路流动，改管和翻转泵方向时重新建立流路。
- 传动采用统一高刚度、无扭转阻尼的弹性连接，接合后允许持续振荡。冲击和持续过载均可能崩断传力路径上的部件，断裂保留此前已经交换的动量；拓扑连接本身不瞬间平均转速。试用场景、参数与验证见 [高刚度传动试用版](TORSION-2026-09-16.md)。
- 动力轴承改为手动组装与拆解：空手右键可在任意转速下组装，成功组装时输出转速立即归零，上游保持原速，随后由高刚度传动计算加速与绷断；再次右键立即拆回方块并解除工作负载。有动力、惰行或停转均保留手动选择的组装状态，拆解后不会自动重装，自动放置选项已移除。随主轴旋转的非空气方块均视为等质量单位立方体，每块增加 `0.0001×(1+6r²) su/RPM³`，`r` 为方块中心到旋转轴的距离，材质与内部动力方块类型不改变权重。护目镜显示输出转速，拆解后为 0；运行中读档保留转速，需要平缓接合时可外接离合器。详情见 [设计文档](DESIGN.md#41-动力轴承的结构与起停)。
- 风车、钟表轴承、活塞、绳索滑轮、升降机和移动龙门架使用相同的方块质量、空气阻力及实际作业负载；旋转考虑半径，平动考虑总质量与传动比例。保留这些设备的原有操作，不加入水阻力或空载固定摩擦。动态钻头、锯、收割机、犁和滚轮随结构移动完成作业，切削负载使结构减速，停转冻结进度；机械手保留驻留动作。列车列为待办。详情见 [动态结构物理](CONTRAPTION-PHYSICS-2026-09-30.md)。
- 稳定子结构也计入主驱动轴的质量、空气阻力及工具耗功。保持朝向的吊舱按挂点平动计算；组装后立即拆解会一并还原，子实体分批加载保留完整物理摘要。详情见 [稳定子结构](CONTRAPTION-PHYSICS-2026-09-30.md#稳定子结构)。
- 2026-10-01 动态结构试用标定：每块自身惯量 `0.0001`、统一质量 `0.0006`，结构惯量与空气阻力均降为初始标定的 `1/100`，保留半径平方、外露面积及实际作业负载。含轴承本体的 9×9 一层实心结构约为 `0.67`，17×17 约为 `8.36`；飞轮为 `0.5`。旧存档的结构摘要自动换算，并保留转速与转角。详情见 [试用标定](CONTRAPTION-PHYSICS-2026-09-30.md#2026-10-01试用标定)。
- 动力机器与传动方块按等级设置结构强度，安山机器及传动件默认 **65536**、黄铜等级 **262144 su/RPM**；创造马达本体为 **∞**，不会因结构过载损坏，相连传动件仍受自身强度限制。护目镜正常视图统一显示，惯量不再决定强度。
- 粉碎轮按重型转子标定，每只惯量为 **0.10 su/RPM³**（普通机器的 10 倍），一对为 0.20；结构强度采用黄铜等级 **262144 su/RPM**。相同扭矩下加减速更缓，同转速下储存更多动能。
- 离合器支持红石强度调节：0 级完全接合、1–14 级调节压紧程度、15 级完全分离。传递扭矩上限为 `1024 × (15 − 信号强度) / 15`；负载较轻时同步并锁止，超出摩擦能力时打滑。锁止不会取消扭矩上限；同侧连接和刚性旁路分别承受实际载荷。
- 黄铜离合器是新增的重载升级版，额定上限为 `32768 su/RPM`。空手瞄准侧面旋钮，长按右键即可打开 0–100% 咬合度滑条，无需扳手，步进 1%，默认 100%。实际扭矩上限为 `32768 × 设定咬合度 × (15 − 红石强度) / 15`；滑条 0% 或红石 15 均完全分离，撤去红石后恢复设定值。咬合度限制传递扭矩，轻负载下半联动也能同步锁止。设置支持存档、蓝图和剪贴板；滑条显示“咬合度”和百分比，护目镜保留实际传递扭矩与滑差。
- 转速控制器改为速比控制器：显示 `+2×` 表示输出为输入的两倍，负号反转，`0×` 断开。内部存档值仍为速比的 16 倍。
- 移除 Create 的转速上限设置。转速表量程独立于轴速：手持扳手瞄准表盘，按住右键选择 64、256、1024……1048576 RPM，默认 256。指针按实际转速绝对值线性移动，超量程保持满格；护目镜显示带符号的实际转速、量程和超量程提示。比较器按固定量程输出 0–15，停转为 0。量程随方块保存，也支持剪贴板复制。
- 冲压、石磨、搅拌、锯切、粉碎、机械手和机械合成按实际轴行程累计加工进度；钻头与横向锯的方块破坏、机械臂的取放动作也接入同一物理时钟，停转保留进度，机械臂动作不再封顶于 256 RPM。
- 程序变速箱的转角、距离指令按真实输出轴累计行程，变速与停转不会重置指令。等待时间仍按游戏 tick 计时，红石等待仍由脉冲继续；输出断开后保留惰行。
- 鼓风机加工随实际转速加快，并采用边际收益递减的曲线；64 RPM 保持配置的基准耗时，停转不再提供加工进度。清洗、熔炼等仍要求对应介质，传送带、置物台和掉落物均保留小数加工进度。详情见 [连续机器适配](CONTINUOUS-MACHINES-2026-09-30.md)。
- 地面冲压会跳过无冲压配方的掉落物，成品留在原地也能继续投料；加工数量遵循 Create 的批量冲压配置。
- 具有工作循环的机器待机时不消耗扭矩，开始动作后恢复额定负载；冲压机的下压、加工和回程都计入工作。待机仍保留惯量，接入旋转网络时仍会分摊动量。鼓风机、泵等持续运转设备保留各自的负载规则，具体范围见设计文档。
- 飞轮惯量为 `0.5 su/RPM³`；轮体和中心轴共用网络角度，取消原版额外的起停缓动。普通渲染和 Flywheel 实例渲染使用相同运动。离合器空输出端完全分离后保持当时转速，有外接传动时跟随输出网络。
- 联网轴、齿轮及机器动画按相邻服务端累计角度插值，避免将高频弹性振动的瞬时转速外推成大幅抖动；没有新数据时停在已知角度。该修复保留实际转速读数和原有物理参数，验证见 [逐轴动画修复](TORSION-2026-09-16.md#2026-09-30逐轴角度插值)。
- 普通和黄铜离合器连接大齿轮时，输出半轴沿用邻接中心轴的角度偏移，避免误用齿面的 11.25° 错齿偏移造成接缝错位。验证见 [离合器轴接缝修复](TORSION-2026-09-16.md#2026-09-30离合器与大齿轮的轴接缝)。
- 护目镜提供两种视图：正常时的动力学视图按设备显示实际转速、当前方块的转动惯量（`su/RPM³`）、扭矩、设备状态、动力源负载率，以及离合器滑差、速比和泵的等效扬程；潜行时查看本体动能、所属网络总动能、本体弹性势能、所属网络总弹性势能和功率。弹性势能由实际连接的扭转状态计算，本体值统计分配给当前方块各端口的储能，所有成员的本体值相加等于网络总量。蒸汽机常驻显示转动惯量、转速、驱动状态、调速目标、供汽旁通比例、负载率和扭矩，状态为蒸汽驱动、调速排汽、无供汽或换向制动；能量视图还显示排汽损失功率。底部提示当前绑定的潜行键。
- 负载率统一为所属网络的持续负载需求与当前可用驱动力之比：运行时按功率汇总，整体停转时按折算后的起动扭矩比较。包括工作机器、泵、风扇及实际传动损耗；飞轮加速和弹性储能不算负载。允许超过 100%，没有主动供能时显示“无动力”。读数由服务端同步，平衡转速下的 100% 表示收支平衡。定义和体验见 [负载率说明](LOAD-FACTOR-2026-09-16.md)。

加工改用双精度物理状态和实际轴行程，阶段结束后立即停止对应负载。相同配方、批量与完整动作的额定加工功在已适配路径中不再随 RPM 改变；验证结果与边界见 [加工耗功修正记录](MACHINING-2026-09-15.md)。

## 黄铜离合器配方

- **复合摩擦片 ×2**：铁板、皮革、黑曜石粉末、黏液球各 1 个，使用动力冲压机在工作盆中压块，无需加热。
- **黄铜离合器 ×1**：工作台有序合成，黄铜机壳放上下、复合摩擦片放左右、中央放普通离合器。

两种新物品位于“微分动力”（Differential Create）创造分类，搜索栏悬浮提示的蓝字也显示该名称，配方可在 JEI 中查看。黄铜离合器物品模型保留方块的外壳、内凹轴承与旋钮，图标中传动杆朝右；复合摩擦片采用 16×16 透明贴图。制作与控制验证见 [黄铜离合器实现记录](BRASS-CLUTCH-2026-09-15.md)。

## 构建与验证

```powershell
.\gradlew.bat build runGameTestServer
```

Linux 对应命令为 `./gradlew build runGameTestServer`。首次运行需要下载依赖。

成品：`build/libs/differentialcreate-1.0.0.jar`。客户端和服务端均安装同一版本，并安装对应的 Create 及其依赖；同步兼容版本已升级为 7，不能与旧版客户端混用。

`build` 自动运行不依赖游戏启动的数值回归，覆盖扭转、离合器、求解精度、反复补轴、蒸汽驱动、负载率、渲染数学、鼓风加工速率、动态结构几何和工具接触轨迹。`runGameTestServer` 运行物理、拓扑、碰撞、加工耗功、离合器控制与制作、创造物品栏、相位对齐、蒸汽机、水泵、转速表，以及静态方块破坏、机械臂、鼓风配方、程序变速箱、动力轴承起停与读档、动态结构质量／阻力／作业、材料强度、弹性势能读数、稳定子结构和连续移动作业回归，共 **73 组游戏测试**。测试使用独立的 `run-gametest/`，无需删除开发世界 `run/world`。CI 同时执行这两项并保存测试日志。

## 当前边界

已通过的自动化验证不等于完成所有场景的验收。多人中途加入/切维度、真实跨区块卸载重载、Flywheel 开关两种渲染路径、复杂管网及全部配方组合还需要客户端实测。

泵采用管路端点平均高差的等效负载；动态结构覆盖动力／风车／钟表轴承、活塞、绳索／升降机滑轮及移动龙门架。质量采用等质量方块，空气采用外露面平方阻力标定，不模拟真实流场与水阻力。列车列为后续待办，矿车等独立载具及其他附属模组的特殊逻辑尚未全面适配。

动力泵与管网后续计划按流体力学思想改造，重新研究压差、扬程、流量与轴端耗功的耦合；目前处于待设计阶段，见 [动力泵改造待办](DESIGN.md#101-动力泵与管网的流体力学改造2026-10-01)。

数值标定目前集中在 `PhysicsTuning`、`InertiaRegistry` 和 `ContraptionGeometry`；黄铜强度名单使用方块标签，尚未提供配置界面。
