# 微分动力（Differential Create）

微分动力是 Create 的动力学附属模组，模组 ID 为 `differentialcreate`。当前目标版本为 Minecraft 1.21.1、NeoForge 21.1.238、Create 6.0.10-281，使用 Java 21。

动力源提供扭矩，负载和惯量共同决定转速。机器带载会减速，断开动力后可以靠储能继续工作，动力不足时逐渐停转。

## 主要玩法

- **动力源**：水车和风车按动力曲线输出；蒸汽机共享锅炉供汽，低速受扭矩限制、高速受功率限制，默认空载趋近 512 RPM。断汽后保留惰行，外部动力可以使轴超过调速目标。搭建与观察步骤见 [蒸汽机体验指南](docs/STEAM.md)。
- **弹性传动**：轴、齿轮和机器通过有限刚度连接，接合后允许振荡，冲击与持续过载都可能崩断部件。安山等级强度为 65536、黄铜等级为 262144 su/RPM；创造马达本体为无限强度。
- **离合器**：红石 0 级接合、15 级分离、1–14 级调节传递扭矩。普通版额定上限为 1024、黄铜版为 32768 su/RPM。黄铜版可空手瞄准侧面旋钮并长按右键，设置 0–100% 咬合度；轻负载下半联动仍能同步，超限时打滑。
- **连续加工**：冲压、石磨、搅拌、锯切、粉碎、机械手、机械合成、静态方块破坏和机械臂动作按实际轴行程推进。停转保留进度，动作完成立即释放工作负载。鼓风加工保留原版固定计时，转速影响气流范围，不改变加工速度；风机仍承受空气阻力。
- **粉碎轮**：两轮共同进给，支持异速、同向异速和一侧停转；同向同速不加工。整组加工保留对数批量优势，64 件需要单件的 6 倍工作量，按数量逐次执行原生配方并整批出料。
- **背罐充气**：铜背罐和下界合金背罐按实际轴行程充气，128 RPM 每 tick 充入 1 点空气，正反转均可。停转、拆放和穿戴保留小数进度；充满或水淹时卸载，水淹仍沿用原版停充规则。
- **弹射置物台**：按实际轴行程回卷，充满后卸载，可断电发射；改远目标补足差额，改近目标丢弃超额，每次发射用尽本轮额度。已飞出的物品保留各自的目标轨迹，批量和实体弹射沿用原版规则。
- **动态结构**：动力轴承空手右键组装或拆解，成功组装时输出从零速开始；风车、钟表轴承、活塞、滑轮和移动龙门架保留原有操作。结构质量、空气阻力和实际工具作业都会影响运动，稳定子结构也计入。操作与边界见 [动态结构说明](docs/CONTRAPTIONS.md)。
- **矿车**：未装配矿车保留接近原版的加速、惰行、燃料与运输行为，底车等效惯量为 0.01；装配体增加惯量与空气阻力，铁轨和熔炉以有限能力驱动，联结按实际惯量传递反作用。钻头、锯等连续工具按实际进给耗功，动能耗尽时保留进度，不使用原生计时暂停。见[矿车说明](docs/MINECARTS.md)和[玩家操作测试覆盖](docs/MINECART_TEST_MATRIX.md)。
- **列车**：蒸汽引擎右键轮组即可升级，继续安装冷凝管可将该引擎的净耗水降至 10%；两种安装沿用原版机壳制作的音效与粒子。供汽软管直接连接锅炉与动力轮组，从整列挂载库存实际扣水、取燃料。速度由动力、质量、坡度和阻力决定，移除原版速度上限及 GUI 配置。档把提供 R、N、1–5 手动档位，默认 W 驱动、S 刹车、X 升档、Z 降档；列车员按转速选档，玩家接管后停止选档。见[列车搭建与边界](docs/TRAINS.md)。
- **移动式接口**：物品与流体共用有限制动、停稳接合和自动空闲放行流程。比较器只在允许传输时输出 15，其余时间为 0，可用作离合器反馈；固定端通电立即关闭库存并收回。精确机器先用程序变速箱或控制铁轨定位。搭建与附属模组扩展见[接口使用指南](docs/PORTABLE_STORAGE.md)。
- **速比与指令**：转速控制器改为速比控制器，1× 居中，左右分别减速和增速；`+2×` 表示二倍增速，负号反转，`0×` 断开。Ctrl+右键可精确输入 1/16 的倍数。可编程齿轮箱控制输出角度、距离和等待，按负载提前制动；同向连续动作可保持转速，反向与结束到位后停靠。见[动力行为与测试](docs/KINETIC_COVERAGE.md)。
- **储能与显示**：飞轮惯量为 0.5 su/RPM³，每只粉碎轮为 0.10。轴和机器动画播放服务器累计角度，护目镜显示实际转速、惯量、扭矩与结构强度；潜行查看本体和网络的动能、弹性势能与功率。
- **负载率**：动力源护目镜与负载表共用物理读数，运行时比较网络的持续需求功率与可用驱动功率，整体停转时暂沿用现有起动扭矩预算。加速储能不算持续负载，100% 表示当前收支平衡。负载表采用非线性指针行程，100% 居中、∞% 位于终点；无有效数值时指针进入斜线休止区，护目镜区分无动力、制动、未定义和等待数据。比较器与显示链接也已接入；零速右极限求值仍待单独实现，见 [设计文档](DESIGN.md#8-显示与负载率)。
- **转速表**：移除原版轴速上限设置。手持扳手瞄准表盘并长按右键，可选择 64–1048576 RPM 量程；默认 256，指针与比较器按固定量程输出，超量程仍显示真实转速。

动力泵与管道使用不可压缩队列：新管全空气，每格保存有序的空气与真实流体，保留重力、水位差和真实泵负载，不再允许水流驱动泵轴。空管泵可以引液，没有排气路径会困气。泵的增压方向只由扳手朝向决定，输入轴正反转均向同一端增压。完整规则见 [流体说明](docs/FLUIDS.md)。

思索优先保留机械动力原版的场景、镜头、字幕位置和节奏，仅对与微分动力规则冲突的文字或操作做最小修改；储能、连续加工和蒸汽轮组等内容另有独立补充教程。思索与物品栏提示提供中英文说明，入口与验证见[思索及物品提示](docs/PONDER.md)。

## 黄铜离合器配方

- **复合摩擦片 ×2**：铁板、皮革、黑曜石粉末、黏液球各 1 个，在工作盆中动力冲压，无需加热。
- **黄铜离合器 ×1**：工作台有序合成，黄铜机壳放上下、复合摩擦片放左右、中央放普通离合器。

两种新物品位于“微分动力”（Differential Create）创造分类，配方可在 JEI 中查看。咬合度支持存档、蓝图和剪贴板复制。

## 构建与验证

```powershell
.\gradlew.bat build runGameTestServer runVirtualAirServer
```

Linux 使用 `./gradlew build runGameTestServer runVirtualAirServer`，首次运行需要下载依赖。成品位于 `build/libs/differentialcreate-1.0.0.jar`。

游戏集成测试、客户端检查和测试结构放在 `src/gameTest/`，纯数值回归放在 `src/physicsTest/`。开发运行配置会加载游戏测试，正式 JAR 只包含 `src/main/` 的运行代码和资源；`build` 同时检查发布包没有混入测试文件或对测试类的依赖。

客户端和服务端均安装同一版本，并安装对应的 Create 及其依赖。当前网络兼容版本为 **22**，以 [DifferentialCreate 的网络注册值](src/main/java/com/diliupengyun/differential_create/DifferentialCreate.java) 为准；列车、机械手动画、结构姿态、负载率状态、弹射轨迹、粉碎轮反力与接口状态需客户端、服务端一起更新。

`build` 自动运行数值回归；`runGameTestServer` 验证拓扑、配方、物品控制、供汽和动态结构，默认使用 `run-gametest/`。`runVirtualAirServer` 在 `build/` 中运行流体、机器、动态管网与卸载场景，可用 `-PvirtualAirSelect=pump_direction_.*,structure_.*` 选择子集。CI 执行完整构建、常规 GameTest、流体、背罐、弹射置物台及粉碎轮专项并保存日志，验证入口见 [设计文档](DESIGN.md#9-验证与维护) 和 [流体覆盖矩阵](docs/FLUID_COVERAGE.md)。

专项性能命令为 `.\gradlew.bat runFluidBenchmarkServer`，可用 `-PfluidPerfCase=loops` 选择多泵回路；类别和测量范围见 [性能测试](docs/FLUID_PERFORMANCE.md)。

列车专项验证使用 `.\gradlew.bat runTrainCoverageServer runTrainClientSmoke`，测试目录均位于 `build/`；客户端检查自动退出。搭建、刻度和覆盖范围见[列车说明](docs/TRAINS.md)。

负载表专项使用 `.\gradlew.bat runLoadGaugeServer runLoadGaugeClientSmoke`，在 `build/load-gauge/` 下验证真实仪表、比较器、显示链接和转速表兼容性；客户端不打开存档，使用实际烘焙模型生成 `build/load-gauge/preview.png` 后自动退出。表盘资源可用 `python tools/generate_load_gauge.py` 重建。

背罐专项使用 `.\gradlew.bat runBacktankServer`，在 `build/backtank/` 的独立世界验证两种材质的充气、负载及方块与物品转换，覆盖范围见[动力覆盖](docs/KINETIC_COVERAGE.md#背罐充气)。

弹射置物台专项使用 `.\gradlew.bat runEjectorServer runEjectorClientSmoke`，在 `build/ejector/` 的独立世界验证回卷、耗功、触发、在途物品和客户端显示；客户端检查完成后自动退出，覆盖范围见[动力覆盖](docs/KINETIC_COVERAGE.md#弹射置物台)。

粉碎轮专项使用 `.\gradlew.bat runCrusherServer`，在 `build/crusher/` 的独立世界验证双轮反力、进度、批量、独立驱动和离合滑移；覆盖范围见[动力覆盖](docs/KINETIC_COVERAGE.md#粉碎轮双轮作业)。

传送带表面专项使用 `.\gradlew.bat runBeltClientSmoke`，在 `build/belt/` 的独立世界让真实传送带从 32 RPM 加速到 256 RPM，核对上下表面相位随累计行程连续变化、不再按绝对渲染时间跳变；客户端检查完成后自动退出。

## 当前边界与待办

结构使用等质量方块与自身遮挡后的平方空气阻力，不模拟结构重力势能、内容物质量、真实流场或水阻力。矿车已适配惯量、驱动、阻力、连续工具耗功及转向圆弧作业；列车已接入蒸汽动力、手动档位、真实资源消耗和有限制动。移动机械手已有独立作业取力或有限储能，移动式接口也已接入列车的物理制动与库存会话。列车弯轨作业、载具机械手的驻车外部补能、复杂车队与多人体验仍待适配或验收，其他附属模组的特殊逻辑尚未全面适配。

管网不模拟真空、压缩、密度分层、同口逆向交换或管内反应，泛用机器使用近似水头。原生整数接口保留真实小数余量，普通重载不补气。流体预算不足时推迟更新，不积累补算任务。完整燃料链、多人中途加入或切维度、长期大型工厂、全部配方组合与完整客户端交互仍需专项验收。

参数目前集中在 `PhysicsTuning`、`InertiaRegistry` 和 `ContraptionGeometry`，接口制动力标定在 `PortableDocking`；黄铜强度名单使用方块标签，尚无统一配置界面。具体待办见 [设计文档](DESIGN.md#10-后续待办)，其余原生机制的适配现状与建议见[机制盘点](docs/MECHANISM_AUDIT.md)。
