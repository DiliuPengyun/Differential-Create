# 微分动力：矿车测试覆盖

环境：Minecraft 1.21.1、NeoForge 21.1.238、Create 6.0.10-281。本轮以玩家操作和作业状态转换为单位。初始关闭的工具不能代替切到一半再关闭的测试；完成目标也不能代替精确耗功、库存和掉落检查。

## 玩家操作与判据

| 操作 | 自动检查的结果 |
| --- | --- |
| 推动各类原版裸车、载客、入水、加减速 | 速度与实际位移递推、容器满度阻力、燃料、水中倍率、轨道形态和速度上限 |
| 装配、拆解、激活铁轨卸载 | 惯量只接入一次；移除不恢复已用动能；取消未完成工作；熔炉车控制器仍绑定当前矿车 |
| 半途关闭工具、反推或改变接触位置 | 清除失效目标和裂纹；不收费；重新进刀不恢复已取消的进度 |
| 换块、挖掉目标、换成基岩 | 不完成失效目标；新目标从新任务开始 |
| 一个物理 tick 内挖掉并放回同种块，包括立即保存重载 | 观察实际替换事件；最终类型相同也不继承旧进度；失效标记随工具 NBT 保存 |
| 行进中替换作物或土壤 | 新事件边界与新力矩一起采样；准确支付新任务的工作量 |
| 动能耗尽、停留、恢复推进 | 零位移无进度；保留已付工作；重新推动、动力铁轨或燃料能恢复切削 |
| 实际控制按钮关闭、重载、重新开启 | 禁用选择持久化；取消半成品；重新作业正常计费 |
| 扳手拾取，右键或发射器重放 | 普通/熔炉/箱子装配车重建惯量和库存；清理原世界进度；按重放后的实际朝向工作 |
| 玩家添煤、达到容量上限、库存缺煤、重新补煤 | 只消耗接受的煤；不生成燃料；停转后补煤保持已知进给方向 |
| 收割、耕地、同格成熟或地面改变 | 实际收割和耕地；无免费进度/重复掉落；关闭或换目标后能重新取得作业 |
| 滚轮停转、关闭、反推、换目标、补货、拆解或重载 | 精确预留、扣料和一次退款；停转保留任务；重载不重复取料 |
| 自然世界 tick 中连续钻三块石头 | 持续行驶；三个目标、三份掉落和三次准确工作量，不重置位置 |
| 拆掉轨道，再铺轨 | 离轨三维位移仍提供付费进给；上轨不重放旧任务；裸车地面和空中运动保留原数值 |
| 弯道、上坡、下坡、转向时暂停 | 原版几何和高度；短工具实际接触；转向暂停设置不被连续作业绕过 |
| 长臂钻头、锯、收割机、犁和滚轮转向 | 目标只被旋转扫到；正向完成，反向或禁用不作业；精确耗功、库存、材料和一次掉落 |
| 单车旋转模式及最后对齐的一步 | 未对齐时暂停；锁定不产生转向进给；最后对齐时恢复付费作业，并同步正确的对齐状态 |
| 转向切到一半停转、重载、反推或替换同种块 | 无动能无进度；原生保存重载保留工作；改变速度后仍完成实际四分之一格冲程；失效目标重新收费 |
| 双车的偏航、俯仰及同 tick 复合姿态 | 用独立的密集原生变换参考选择圆弧中间目标，目标不在两端或端点直线上；两车合计准确支付一次工作 |
| 双车中的静止或暂停支撑 | 只有可移动的支撑支付工作；暂停支撑的存储速度不被当作可用能量 |
| 矿车上的实际竖直动力轴承稳定子结构 | 长臂保持朝向，工具只沿安装点的小圆弧进给；父子实体 tick 不重复作业 |
| 停转时的实际姿态数据包和迟加入状态 | 经原生实体数据包编解码，偏航、俯仰和旋转状态与服务端接受值一致；复制实体的渲染朝向正确 |
| 玩家联结、重复联结、拆开；两车支撑同一结构 | 链接只耗一次；拒绝二车闭环；普通拖车不分走结构质量；双支撑结构和工具只计一次 |
| 实际机械手或存储接口驻留，再禁用手或拆掉对接端 | 原生接触回调产生真实暂停；钻头无位移/免费工作；释放后恢复 |
| 上下车、漏斗/探测/激活铁轨、已点燃 TNT 重载 | 原生坐席、收集开关、检测信号、引信计时与重载 |

## 本轮发现并修复的问题

- 滚轮把零速度当成退刀，取消了已付进度和材料预留。
- 收割机、犁和滚轮在同格重新启用、换目标或补货后不再取得作业。
- 离轨工具没有接入付费进给。
- 熔炉车切削停转后自动补煤，可能失去推进方向。
- `ROTATE_PAUSED` 设置被连续作业绕过。
- 行进中换作物或土壤，旧边界与新力矩不同步，多扣约 11% 能量。
- 熔炉车原生保存读回实体后，控制器失去矿车引用，激活铁轨等行为失效。
- 同种目标快速替换不使旧工作失效；现仅观察正在作业的目标，不保留卸载实体引用。
- 只积分平移，遗漏随后转向产生的工具进给；现将偏航与俯仰圆弧分段计费，并由实际支撑车支付。
- 转向停转后改变速度，旧参考坐标下的剩余冲程缩短；现持久化进给比例，保持剩余的实际切削位移。
- 姿态已前进后重新计算进度比例，与之前采样的力矩不同，导致微小的多扣能量；现用同一事件比例计算负载与进度。
- 客户端独立按原生角速度更新，可能超过服务端付费后的实际姿态；现同步实际姿态与旋转状态。

## 尚未证明的范围

上述服务端测试覆盖有限的状态转换和典型组合，不能穷举所有搭法。

- **复杂车队和完整车体动力学**：已检查单车长臂、双车的偏航、俯仰和复合姿态，以及竖直轴承稳定子结构；平移、偏航和俯仰仍按原生 tick 顺序分段，没有验证任意车队、任意嵌套姿态与同时运动的六自由度车体求解。
- **自然区块卸载、跨维度和存档版本迁移**：已检查真实实体 NBT、延迟乘客、部分任务、材料及失效标记重载，尚未通过真实服务器的区块卸载和跨维度流程验收组合行为。
- **多人客户端**：服务端控制按钮、库存、掉落、运动以及实际姿态的原生数据包往返已检查；真实客户端的插值、裂纹、动画、延迟及多玩家同时操作仍需实机验收。
- **整个车队的机械能守恒**：原生碰撞、坡道修正和联结硬位置校正仍保留原处理，不作完整守恒保证。

## 运行方法

```powershell
.\gradlew.bat build
.\gradlew.bat runMotionCoverageServer '-PmotionSelect=minecart_.+'
.\gradlew.bat runMotionCoverageServer '-PmotionSelect=minecart_turn_.+'
.\gradlew.bat runMotionCoverageServer
.\gradlew.bat runGameTestServer -PregressionRunId=minecart-audit
```

测试输出和临时世界留在忽略目录 `build/`；不清理玩家的 `run/` 或 `run-gametest/`。
