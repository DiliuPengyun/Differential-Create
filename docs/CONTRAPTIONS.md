# 微分动力：动态结构

本文说明动力轴承、风车、钟表轴承、动力活塞、绳索滑轮、升降机和移动龙门架的当前行为。求解器、共同事件时钟与回退规则见 [设计与实现范围](../DESIGN.md#5-积分与客户端)。

物理长度统一按一个方块边长等于 **1 米**，速度、加速度分别使用 **m/s、m/s²**；方块数量和网格落点仍使用“块”“格”。这与当前依赖 Create 6.0.10 的长度标尺一致：[TrackEdge.getLength](https://github.com/Creators-of-Create/Create/blob/mc1.21.1-6.0.10/src/main/java/com/simibubi/create/content/trains/graph/TrackEdge.java) 直接使用世界坐标距离，[TrainMapSync](https://github.com/Creators-of-Create/Create/blob/mc1.21.1-6.0.10/src/main/java/com/simibubi/create/compat/trainmap/TrainMapSync.java) 将导航距离向下取整后交给地图，[英文语言键](https://github.com/Creators-of-Create/Create/blob/mc1.21.1-6.0.10/src/generated/resources/assets/create/lang/en_us.json) `create.train_map.train_moving_to_station` 直接以 `m` 显示。[列车配置](https://github.com/Creators-of-Create/Create/blob/mc1.21.1-6.0.10/src/main/java/com/simibubi/create/infrastructure/config/CTrains.java) 仍称其为 Blocks/Second 和 Blocks/Second²，两者没有额外长度倍率。9.81 m/s² 是微分动力为普通结构设定的重力参数；质量、力矩和能量仍保留现有轴系标定单位。

## 组装与操作

普通动力轴承由空手右键切换组装状态：

- 未组装时，请求在下一 tick 组装；零速、正转和反转均可组装，结构收集及失败提示仍由 Create 处理。
- 成功新装时，输出转子归为精确零速，并立即采用完整结构惯量；失败不改变原转速。上游转子保持原速，随后通过有限刚度接触驱动结构。
- 已组装时，右键立即拆回世界方块；运动、堵转或无动力时均可拆解。结构负载移除，剩余轴承转子保持当时速度。
- 转速变化、动力恢复及网络重建不会自动组装或拆解；断开动力后结构继续受惯性、重力和阻力作用，停转后仍等待手动拆解。

新装归零会消耗原输出转子的动能。轴承没有内置摩擦同步过程，高速接入静止结构可能按正常强度规则绷断较弱的传动件；离合器可限制接入扭矩。

普通动力轴承不再使用三种自动放置选项，旧选项值也不改变手动操作。护目镜显示“输出转速”，未组装时显示零速；能量视图仍统计剩余轴承转子的真实动能。

风车、钟表轴承及平动控制器保留 Create 原有组装、拆解、转向和行程控制。下述规则统一其物理负载，不改变原有操作入口。

## 质量与惯量

每个非空气结构方块都视为等质量单位立方体。材质、形状和内部机器类型不改变质量，结构内的动力方块不再额外贡献独立转子惯量。库存物品、储罐内容物和乘客不另加质量；质量同时决定惯量、升降重力负载和偏心结构的重力矩。

| 标定 | 当前值与规则 |
| --- | --- |
| 方块自身转动惯量 | `J₀ = 0.0001 su/RPM³` |
| 方块质量 | `m = 6J₀ = 0.0006` |
| 旋转方块贡献 | `J_block = 0.0001 + 0.0006r²` |
| 普通活塞、滑轮、龙门架折算半径 | `a = 1200/(512×2π)`，总质量 `M` 的输入端惯量为 `Ma²` |
| 升降机 | 原有行进倍率为 2，折算惯量乘 4 |

`r` 是方块中心到旋转轴的垂直距离。轴经过结构锚点方块中心，局部整数坐标已是中心偏移，不再加半格；沿轴伸长不增加半径项，轴上方块仍有自身惯量。

普通轴承本体惯量为 `0.01`，再加结构贡献。风车不另加逐帆惯量，帆数仍决定原有驱动力；钟表时针按半速折算惯量，乘 `1/4`，分针按全速计算。

平动质量只按方块数量计算，方块离控制器多远不会增加质量。移动龙门架的结构质量挂在当前支撑轴上，越过下一根轴时转移速度与动量，不重复挂到多个轴；镜像滑轮也不重复计入同一平台。

控制器保存结构惯量与阻力摘要，实体较晚加载时继续使用完整负载。结构方块更换使几何缓存失效；龙门架另保存当前速度。

## 稳定子结构

Create 的 `StabilizedContraption` 是独立实体，方块不在主结构列表中。典型例子是摩天轮吊舱：保持世界朝向，挂点随主轮运动。原生子结构不再生成下一层稳定子结构。

每个实体只计入一次，并绑定主结构驱动轴。旋转主结构上的子结构只作整体平动，输入端惯量为：

```text
J_stable = q² × N × 0.0006 × r_mount²
```

其中 `q` 是主结构传动倍率，`N` 是子结构非空气方块数，`r_mount` 是挂点到主转轴的垂直距离。不叠加子结构自转惯量，也不将内部方块偏移当作公转半径。挂点在主轴上时，子结构静止，惯量、空气损失和工具作业速度均为零。

平动主结构上的子结构按总质量及原有线性倍率折算。是否分离子结构继续服从 Create 的 `stabiliseStableContraptions` 配置，默认仍将这些方块合并。

子结构空气阻力按挂点瞬时速度在子结构坐标中的方向计算自身遮挡，保持朝向的吊舱迎风面积可随公转角改变。其钻头、锯、收割机、犁和滚轮按挂点速度作业，内部工具位置不额外增加速度；机械手由独立的作业轴驱动。

组装时按原生 UUID 找到完整负载，在首次实体挂接前安装惯量。立即拆解先挂接已创建的子实体，再由原生流程一并还原；单独拆解子结构会清除其挂接记录。

卸载前摘要统计全部实体。主实体先加载、子实体分批加载时，直到全部挂接才解除摘要，避免负载丢失或重复减速。

## 重力、保持与拆回

重力始终沿世界竖直向下。水平轴上的偏心结构会趋向重心较低的位置，能够反拖相连的动力网络；竖直轴和重心落在轴线上的平衡结构没有重力矩。稳定子结构保持自身空间朝向，它的全部重量通过挂点绕父轴运动，内部偏心不额外叠加父轴重力矩。

| 执行器 | 运动与保持 |
| --- | --- |
| 动力／风车轴承 | 按当前重心和世界姿态计算重力矩；无动力不是驻车，制动能力不足会转动或摆动 |
| 活塞、绳索滑轮 | 按真实位移的竖直分量折算负载；上升消耗势能对应的轴功，下降可以反拖轴系；水平活塞不产生重力驱动 |
| 起重机杆与取物器 | 沿杆方向投影重力；水平杆不受轴向重力驱动，竖直杆能够下滑并反拖当前承载轴；换轴只转移一次结构质量与动量 |
| 钟表轴承、升降机 | 保留原生目标、传动方向和到位控制，按该控制器实际允许的运动映射折算重力；原生暂停由约束承载，不把它们改成自由摆钟或自由落体装置 |

线性执行器使用独立的结构输出节点，结构质量和空气阻力只计入输出；输入轴通过有限传递扭矩驱动输出。到达几何端点时，单侧支撑阻止越界，输入轴仍可转动，反向驱动可离开端点。移动机械手的驻留制动保持有限扭矩，超过制动力的重物仍会滑动。普通轴承继续使用原有转子和接触，不增加自动驻车制动。

普通活塞和绳索滑轮保留实体到达端点后，重力也可以使其离开端点，无须先收到新的转速命令。例如朝下的活塞完全收回时，只限制继续向上收回，仍允许向下伸出。原生端点的 `Waiting` 标记在物理更新时解除，不额外施加双向摩擦制动；旧存档中的该端点等待状态同样处理。行程中途的原生暂停、已耗尽的程序行程和升降机目标控制继续保留各自的约束。

活塞、绳索滑轮撞到障碍时，先执行原生方块化设置；保留为实体的结构将碰撞方向记为单侧支撑，并把它交给同一个输出约束求解。货物静止时重力不再给输入轴增加能量，输入轴仍可保留此前的惯性转动。反向驱动可以离开障碍，移除障碍后自动解除支撑；保存和重新加载会保留并复查接触，避免重载后再次按虚构的下落行程加速。

普通线性结构保留 9.8 m/s、升降机 39.8 m/s 的原生速度上限（20 tick/s 下分别为 0.49 m/tick 和 1.99 m/tick）。该上限由输出制动耗散多余能量，不作为每 tick 都重新出现的位置墙；端点碰停和原生碰撞不产生反弹能量。绳索暂不计算松弛、摆动和弹性，导轨也不计算弯曲或倾覆。

内部取 `g = 9.81 m/s²`。求解器坐标为转数、时间为分钟，动能保持原有 `½J×RPM²` 标定，因此势能采用 `U = 3600g/(4π²) × Σ(mᵢyᵢ)`。自由平移质量在没有轴惯量和阻力时得到 9.81 m/s² 的加速度；接入轴和飞轮后，反射惯量会降低加速度。每段用势能差求重力做功，动力源的功率上限不会截掉重力；事件试算不改世界姿态，接受行程后才更新势能相位。

右键拆回、红石起重机拆回及重新组装保留原生即时放置和整数格取整，不增加等待对齐或补功流程。取整造成的势能跳变允许作为玩法例外，因此反复拆装的跨状态循环不保证能量守恒。护目镜继续显示原有动能与弹性势能，重力势能目前只参与求解，不新增单独读数。

结构实体尚未完整加载时，关联网络暂缓积分，保留原有速度与姿态；全部子结构就绪后再根据实际重心恢复重力，避免先按一部分重量求解。库存、乘客质量及脱离执行器后的自由空间运动不在本次范围内。

偏心轴承不是恒定向下加速：它绕轴下摆、越过最低点、上升再返回。3 块轴承在该拟合窗口的角加速度约 1.30208 rad/s²，加飞轮后约 0.03482 rad/s²。表中的 m/s² 是重心的竖直分量；它同时受到摆角和向心加速度影响，不能直接当作 `g`。平衡轴承、竖直轴承与水平起重机的全部采样中，重心位移和输出转速均为零。

**当时测出的启动边界（已于 2026-10-29 修复）：** 起重机原生 `tickCount > 2` 才允许移动；旧实现的前两个采样 tick 中，实体不动而物理轴速已经累积，第三 tick 开始移动。3 块起重机的逐 tick 位移二阶差分在该跳变处出现约 **24.524 m/s²** 的尖峰；限速前的正常运动阶段约为 9.79～9.81 m/s²。修复后在原生启动等待期间同时约束物理输出，不提前释放重力做功。重新运行同一批 15 个测量场景，3 块起重机启动全过程的最大原始加速度为 **9.80982 m/s²**，0.2～0.8 秒拟合值为 **9.79912 m/s²**，首次可见位移仍在 0.15 秒。1 秒与 6 秒下降距离改为 **3.96965 m、52.91981 m**，1.20 秒的采样区间达到 9.8 m/s 限速。上表保留修复前的历史测量，不能混用于修复后的启动过程。

输入轴与独立结构输出之间有有限刚度，当前接触扭转阻尼为零；接飞轮时逐 tick 速度会有小幅弹性波动。轴承的原生浮点姿态还会放大位置二阶差分的噪声，因此同时保留原始位置、轴速和拟合统计。10 月 28 日两次独立测试世界中的 1815 个相对初始重心位移样本逐项比较，差值小于 `1e-9 m`；当日 15 个测量场景与原有 4 个控制器测试共 19 项通过，仅新增测量工具。10 月 29 日的启动修复改变了控制器等待行为，重力常量及质量、阻力标定保持原值。

## 空气阻力与连续作业

空气阻力考虑每个动态结构自身的几何遮挡。轴向平动按方块投影并集计算，同一列上的方块即使隔着空隙也只增加一次迎风面积。斜向平动沿实际相对风向检查表面采样点是否被本结构的其他方块遮住；完整箱体和封闭箱壳直接使用其外轮廓，斜向面积也不重复计入内壁。

旋转结构沿每个表面采样点的局部切向风向检查遮挡，同时保留该点到轴的距离。相邻内部面、被其他自身方块挡住的面及封闭空腔内壁不产生额外空气阻力；轴上方块仍有自身尺寸产生的阻力。斜向和旋转面沿用每面四点的面积采样与双向平均，未追踪连续空气流场。几何索引按结构缓存，方块更新后失效；斜向风向结果使用有界缓存。质量和惯量仍统计全部实际方块。

阻力随速度平方增长，反向大小相同。空气系数为 `1/(100×64²)`：1 m² 投影面积在 1 m 半径、64 RPM 下的基准阻力扭矩为 `0.01`。自由惰行渐近减速，不在低速突然变成固定刹车；有限刚度、无扭转阻尼的连接仍可产生微小振荡。

这是均匀静止空气的玩法标定，不区分流线外形，不模拟水阻力或空载固定摩擦。活塞、绳索滑轮、电梯、龙门架、装配矿车、机械轴承、钟表轴承及稳定子结构使用同一套自身遮挡规则；不同动态结构之间不相互遮挡。例如沿 X 排列、相隔一格的两个方块，X 投影为 1；3×3×3 的封闭空心壳各轴面积为 9，中心存在真实通孔时相应面积为 8。列车使用独立的整列投影并集，见[列车说明](TRAINS.md)。

钻头、锯、收割机、犁和滚轮按实际运动作业，不因排队任务设置整座结构的 `stall`。轴、接触轨迹和控制器下一次移动使用同一份积分行程；负载使结构减速，动能耗尽且驱动不足时物理停转并保存部分进度。

普通破坏作业的标定行程为 `C = max(0.1,硬度)×1000` 个工具侧 RPM-tick；收割、犁地及单次滚轮铺设为 1000。机械手的普通使用和采掘行程见下节。额定应力 `S` 优先读取 Create 配置，无额定值的移动工具采用 2，滚轮采用 8；每格耗功为 `S×C/1200`。

当前切入行程为 **0.25 米工具侧位移**，若更早离开目标则缩短到剩余接触行程的 90%。输入扭矩由固定耗功除以实际轴侧切入行程；硬度、半径及同时工作的工具数量影响负载，提高轴速不会免除耗功。

普通旋转工具按安装半径作业，稳定子结构工具按挂点半径作业。半径同时影响作业速度和输入扭矩，使同一作业的耗功不随半径变化；普通轴心钻头可通过有限面积刀具的真实旋转加工，轴心稳定子结构仍静止。

平动轨迹按直线求方格边界，旋转轨迹按圆弧解析求交。物理时钟在完成作业、跨格或控制器行程边界处分段，高速运动也访问中间目标；反向试算使用对应方向的接触边界。

收割、犁地和滚轮铺设在接触区间内付清耗功后执行原有世界操作。树木、落沙、掉落和滚轮批量处理继续使用 Create 回调。

## 移动机械手

玩家把机械手、工具或材料箱粘在原有动态结构上，给活塞、轴承或起重机杆供能即可。这里的起重机由 Create 的“起重机杆”和“起重机取物器”组成，即沿长杆移动的结构；不需要额外的控制器、作业端口或机载传动轴。

驱动器内置作业取力和结构移动离合。普通种植、播种、放置、右键使用和一次性实体攻击在真实接触格内付功执行，结构可以继续移动，收回动作不要求驻留。采掘需要对同一方块完成敲击时，移动离合断开，有限扭矩的制动器降低结构的真实速度，输入轴继续驱动机械手；多次敲击保持接触，完成并收回后重新接合。种植机械手不会解除同一结构上采掘机械手的制动。禁用作业的机械手会释放自己的驻留要求。技术说明中的“进给”指把工具送向工作位置的运动。护目镜沿用原有动力学和能量两种视图，机械手的内部取力、制动阶段和作业进度不新增独立读数。

机械手不设置原生整机暂停。制动、接合与结构惯量共同决定停车距离；速度过高而离开触及格时取消该目标，已有动作仍须付功收回。钻头、锯、收割机、犁、滚轮和移动式物品/流体接口使用真实结构驱动轴的速度和位移，不会借用停车期间的机械手作业行程。

采掘每次伸出与收回各消耗 500 个作业轴 RPM-tick，每完整循环消耗 S×1000/1200。普通使用和一次性攻击采用短接触行程，伸出与收回各 64，完整动作消耗 S×128/1200；两种动作都按实际工作轴行程推进。作业速度不足、预计会在完成伸出前离开触及格时，结构自动施加有限制动力，为当前动作争取时间；短动作执行成功后立即解除定位要求，收回期间继续移动。切换使用与攻击模式会取消原有动作，先付功收回，再按新模式重新判断目标，不能把使用的短行程换成免费采掘。提高工作轴转速提高动作频率，每次敲击的破坏强度仍由原生工具、方块与权限规则决定，掉落、工具磨损、材料提取和右键交互沿用 Create。

矿车没有驻车旋转输入。每台机械手的内部作业转子容量为 256，单台取力上限为 128；全车共用最多 256 的取力能力，不能按机械手数量无限叠加。低速时，扣除其他工具和停靠制动负载后，充能最多使用当前动量在一个 tick 内对应的一半反力预算，给起步保留余量。正在作业的机械手先分配，空闲机械手分享余下预算；已禁用且无需收回的机械手不取能。普通使用动作仅补充四个循环的工作储备，采掘保留较大的转子储能；切换动作保留已拥有的真实能量。只按实际移动的已付功充能，达到储备目标时按事件结束该段取力。

矿车机械手消耗作业转子的真实动能。短行程使用较快的内部传动，按折算惯量计算作业速度，换模式保留原有能量。采掘按本轮尚未完成的伸出、收回与剩余敲击判断能否驻车完成；普通使用仅在当前接触动作已经有足够储能、又来不及完成时制动，收回不制动车体。种树仍使用原生右键、树苗和地面规则，正常作业边走边种。没有足够储能时不能靠停车凭空取得作业动力，需要动力轨、炉车或控制轨提供真实供能；物理停车后由动力铁轨沿已知方向重新起步。作业进度、采掘进度、转子储能和独立结构驱动轴状态均保存到存档；完成记录防止收回或读档后重复使用同一目标，目标替换、移出触及格或禁用不会把旧目标的进度交给新目标。

完全没有储能的新装矿车应在第一处作业位置前留出短的起步段；16 台种植机械手的测试用两格通电轨道完成初次充能。已经充能的机械手可以直接开工。车尚未取得能量时直接贴着目标起步，仍可能在充能完成前离开触及格。树苗和作物会先检查地面是否支持生长，经过无效地面时不会空停一轮。

## 接触刷新、停转与存档

钻头和锯在物理阶段开始时检查当前接触格。空闲工具发现迟放或替换的目标时重新执行原生检查，已有作业继续保存进度；空格不反复触发实体伤害，不可破坏目标仍由原生规则排除。

每个替换方块重新计功。零速可以发现目标，但不会推进切削；完成、取消、禁用及重新加载会清除临时观察状态，恢复后重新检查。工具离开目标、目标状态改变、禁用或拆解时取消未完成作业，滚轮未使用的预留材料返还。

小数进度、切入行程、接触目标及材料预留保存在 actor NBT 中。已付功、尚未被控制器消费的输出位移随实体保存，恢复后只消费一次；消费后的位移不再保存。

连续作业的线性执行器在停转和换向通知时保持 `offset` 小数位置，不执行原生整格归位。下一次控制器 tick 只消费实际积分位移；实际反转按有符号行程回缩，非零运动继续执行原生碰撞及行程控制。

零长度运动向量统一为 `Vec3.ZERO`，避免浮点负零进入地形碰撞并将静止结构归位。轴承停转或反向时也保持实际角度，不因速度通知取整。

连续工具与机械手混合时，结构驱动轴、机械手作业轴分别计功，不使用原生结构暂停。物理驻留时连续工具只读取真实结构运动，机械手仍可消耗输入轴或内部转子的能量作业；姿态快照和待消费位移保持实际位置。重新移动后只应用新产生的结构位移，不重放驻留期间的工作轴行程。

活塞等执行器到达行程端点时，保留驱动方向和两侧限位；朝受阻方向旋转不产生进给或切削功。若动力源在同一 tick 内将轴推回可运动方向，物理时钟先停在恢复方向的事件上，再重新读取工具接触与负载，剩余时间的进给正常计功。原生暂停和双向行程限制不会被该事件解除。

控制器使用统一结构摘要保存惯量、空气阻力和子结构数量。当前格式重复读写不缩放数值，读档保留转速、转角和组装状态，不执行新装归零；不转换早期惯量校准或只有轴承摘要的旧数据。

## 轴承结构姿态同步

运行中的机械／风车轴承在现有转子包中携带实体 ID 和装配相对角度，包含已积分、待控制器消费的位移。快照读取不消费或累计位移；服务器跟踪实际应用的有符号行程，保留整圈和程序行程限位。

轴的累计相位与结构装配原点分别保存，重新装配、实体重载及网络重建不混用角度基准。客户端协议为 **17**，联机双方需要相同协议版本。

客户端按已确认的连续角度播放姿态。普通渲染、Flywheel 和乘客坐标变换共用插值；权威姿态可用时停用原生 RPM 推进和角度纠偏，不用终点 RPM 预测整 tick 的结构位置。没有可播放样本时保持确认姿态，冻结时保持当前显示位置。

结构姿态保留一个确认样本作为缓冲，通常额外增加约 50 ms 显示延迟。相邻 tick 零包／双包到达时逐个播放服务器端点，避免零位移和双倍位移交替。缓冲仅用于结构姿态，不改变转子包数量、服务器积分或接触查询。

缓冲使用固定八项 `double` 环形数组。长时间客户端停顿造成超过三份待播样本时，保留最近两份重新衔接；真实断流则耗尽缓冲后停在确认端点。冻结恢复先完成中断线段，新实体清除旧装配的待播姿态。

轴承顶盘两条渲染路径传入 `partialTick-1`，同步接口将其加一后读取同一插值线段；动态结构直接使用 `partialTick`。这使顶盘与结构在减速、停转、反转及多圈运动时保持相同姿态。

## 限制与维护入口

- 列车的质量、驱动、空气阻力及作业负载由[列车系统](TRAINS.md)单独计算；矿车的惯量、驱动、阻力与连续工具耗功见[矿车说明](MINECARTS.md)，矿车机械手使用上述有限储能和物理制动规则。
- 真实跨区块卸载重载、多人中途加入／切维度和复杂动态结构的客户端体验仍需实测。
- 偶发加工边界求解异常仍待定位；未复现的问题不能视为已修复，极端输入也不保证收敛。
- 当前等质量、空气和切入距离均为集中标定，尚无配置界面；其他附属模组的特殊逻辑未全面覆盖。

质量与几何维护入口为 [ContraptionGeometry](../src/main/java/com/diliupengyun/differential_create/kinetics/ContraptionGeometry.java) 和 [ContraptionPhysics](../src/main/java/com/diliupengyun/differential_create/kinetics/ContraptionPhysics.java)；移动作业入口为 [ContraptionActorWork](../src/main/java/com/diliupengyun/differential_create/kinetics/ContraptionActorWork.java) 和 [ContraptionMotion](../src/main/java/com/diliupengyun/differential_create/kinetics/ContraptionMotion.java)。

姿态播放入口为 [BearingAnimation](../src/main/java/com/diliupengyun/differential_create/client/BearingAnimation.java)。当前自动化覆盖见 [结构测试](../src/gameTest/java/com/diliupengyun/differential_create/tests/ContraptionPhysicsTests.java)、[稳定子结构测试](../src/gameTest/java/com/diliupengyun/differential_create/tests/NestedContraptionTests.java) 和 [轴承测试](../src/gameTest/java/com/diliupengyun/differential_create/tests/BearingPhysicsTests.java)；构建和验证命令见 [README](../README.md#构建与验证)。
